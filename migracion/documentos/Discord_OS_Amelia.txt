⚡ OS Amelia — Major Milestone
Large architectural update bringing Pi layer compatibility, face recognition groundwork, app system, and screensaver restructuring.

🔌 Skills Plugin System
The old ~530-line if-elif chain is gone. Skills are now auto-discovered plugins.
Each tool is a standalone skill_*.py file in src/skills/ — drop a file in, restart, it works
Each skill exports a SKILL dict (name + LLM prompt definition + optional examples) and an execute() function
Skill prompt definitions and few-shot examples are dynamically injected into the system prompt
19 skills: web_search capture_camera_view take_photo execute_movement generate_image adjust_persona identify_speaker_name volume browser home_assistant system_control launch_retropie reminder discord sandbox_exec network_camera generate_music tars_radio example
Multi-skill fix: multiple skills in one turn now join replies instead of overwriting
module_engine.py FUNCTION_REGISTRY removed entirely
🎙️ Streaming LLM + Sentence TTS Pipeline
TARS now speaks after the first sentence instead of waiting for the full reply.
SentenceTTSPipeline splits tokens at sentence boundaries (min 20 chars, min clause 12 chars)
Voice mode and web UI share the same pipeline backend
Device speakers and web browser play in parallel with LLM generation
Real-time tokens stream in the web UI as they're generated
Follow-up message fix: web search and tools now emit and speak the updated text correctly

👤 Speaker ID — Full Rewrite
Three-tier threshold model: consistency (0.55) → soft match (0.65) → high-confidence (0.75)
Atomic saves: writes temp file then renames to prevent corruption
Auto-merge duplicate unknown profiles; real names in memory/prompts (no more unknown)
wait_for_identification() waits up to 2.0s for speaker ID before displaying user message
Deferred name correction: UI message bubble updates via socket event after identification
Barge-in fix: TARS's own TTS no longer poisons speaker detection
Browser mic audio submitted to speaker ID for web voice mode
Default threshold raised from 0.5 → 0.75
📊 Dashboard Tab (New in Web UI)

📈 Graph — D3.js memory/knowledge graph with detail drawer

⏰ Heartbeat System & Reminder Skill

🧬 Identity Coordinator (module_identity.py)

module_speaker_id.py and face recognition both feed into it
🔔 Atomik Wake Word — CNN/ONNX + Multi-Gate Pipeline
Full rewrite from template matching to a dual-mode architecture.

Template mode (cosine similarity — recommended default):
Records 5 template utterances during setup, augmented with time-stretch, pitch-shift, gain variation, noise
MFCC cosine similarity matching — most reliable for custom wake words out of the box

Model mode (CNN/ONNX neural network):
Pre-trained ONNX model from tts/{wake_word}.onnx
TinyClassifier — pure-numpy 1D CNN with Adam optimizer, trained on-device as fallback
5-gate pre-filter: energy, adaptive SNR, crest factor, spectral speech band, low-freq rejection
Confirmation window (2 above-threshold scores in 5 checks) + post-detection _is_speech_like() validation
MFCC + delta + delta-delta features (39 channels)
Synthetic negative audio generation for training (40 clips: white/pink noise, babble, tonal, rumble, clicks)

Config: atomik_mode = auto | model | template
🚪 Wake Word Gates
Post-detection gates applied to all wake word backends (atomik, sherpa-onnx, fastrtc).
🗣️ Speaker Verify (vad_speaker_verify) — match voice against enrolled speakers; modes: off / any / specific name. Uses lower threshold (0.60) than normal speaker ID (0.75)
👁️ Presence Gate (vad_presence_gate) — require a face on camera; modes: off / any / known
📝 Transcript Verify (vad_transcript_verify) — confirm wake word was actually spoken via STT with exact + fuzzy matching
All gates optional, disabled by default, run synchronously before triggering wake callback

If you're already using V3 hardware, you don't need to do anything special — just update the software.

To update:
Open a terminal in your TARS-AI folder
Run: git pull
Then run: ./Install.sh

If you've modified files locally: git pull might fail. If you're okay discarding local edits, reset to latest:
git reset --hard
git pull

⚠️ This will delete any local changes. Make a backup first if you want to keep them.
