# Recursos excluidos de esta copia de desarrollo

Esta copia está pensada para continuar Enzo en un Mac mini y desplegarlo después en la Raspberry Pi. Para mantener la clonación rápida no incluye estos recursos del proyecto comunitario:

- Archivos CAD e impresión 3D (`3d Printer Files/`).
- Versión estática del robot (`Static Version (no motors)/`).
- Medios de muestra (`media/`).
- Música y recursos audiovisuales de la interfaz (`src/music/` y `src/modules/UI/`).

No se necesitan para el objetivo actual: conversación, voz, cámara bajo demanda, memoria y configuración headless. Permanecen disponibles en el repositorio comunitario original si se requieren para la fase física.

Todo el código Python relevante, configuración, tests, personalidad de Enzo, documentación y contexto de migración sí se incluyen aquí.
